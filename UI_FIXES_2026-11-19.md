# Akaora Meet — ATELIER UI corrections (19 Nov 2026)

Based on the supplied screenshots, this patch focuses on **layout and visual defects only**. The Firebase/WebRTC code is unchanged from the previous ATELIER edition.

- Unified theme styles across `styles.css`, `redesign.css`, and `classic.css` by applying a final scoped stylesheet, `polish.css`.
- Replaced the homepage's off-white/white header mismatch with a continuous editorial canvas.
- Corrected Create/Join input focus (underline, rather than an intrusive orange rectangle), oversized type spacing, room-code and toggle alignment.
- Repaired overlapping and low-contrast in-call status, clock, host name, branding, room code, and action buttons in light/dark themes.
- Made the meeting stage and call toolbar separate regions, preventing controls from covering video.
- Removed inherited rainbow backgrounds from meeting controls, with neutral icon buttons and restrained state colors.
- Corrected avatar label and video control icon contrast, video-tile labels, and initial invite sheet placement.
- Ensured small screens show all 9 controls in a 2-row layout and that meeting header actions remain on the same row.
- Moved toast notifications above the call dock so they don't obscure action buttons.
- Preserved all existing app IDs/event bindings, SVG icons, room controls, sharing, calls, chat, and host permissions.

## Running

Extract the ZIP and double-click `start website.bat` inside `akaorameet-main`. Visit `http://localhost:4173/`. Python 3 is required; Firebase features require correct database setup and internet. For real mic/camera tests across distinct devices use HTTPS and working ICE/TURN configuration.

## Testing limitations

Static JavaScript syntax and offline mocked-Firebase desktop/mobile UI interaction checks were performed. Production network-based multi-device media connectivity and backend database permissions are not validated by this visual patch.
